# D1 — temporal dataflow and Trace coordinate contract

Date: 2026-08-24  
Status: completed read-only audit and geometry tests; no Motus training change.

## Question

Can a temporal delta be constructed on the post-merge Qwen visual grid without
silently treating image coordinates as physical correspondence?

## What changed

Only the offline Trace cache preprocessing and test/audit utilities changed. The
Motus model, the Trace model, Qwen weights, training loop, inference API, and
action/video sampling algorithms were not modified.

## Coordinate contract

Qwen conditioning images are `[3, 384, 320]`. Because the image is portrait,
Trace preprocessing transposes it, scales the long side to 512, then crops to a
multiple of 16. For this input the persisted metadata is:

```text
qwen_h=384, qwen_w=320, transposed=true
trace_input_h=416, trace_input_w=512
resize_scale=1.3333333333
crop_top=0, crop_left=0, crop_h=416, crop_w=512
resized_h=427, resized_w=512
```

The cache map has the unambiguous direction **current Qwen token → previous Qwen
token coordinate**. It is stored as `source_uv` for `grid_sample` with
`align_corners=True`.

## Boundary tests

The synthetic fields isolate coordinate conventions from learned Trace quality.

| Test | Expected result | Observed result |
| --- | --- | --- |
| Identity: `I_prev = I_cur` | Every 12×10 current token maps to itself. | mean displacement `0.00937010`, max `0.01576082`, valid fraction `1.0`. |
| Translation: `I_cur = shift(I_prev, dx=32, dy=0)` | Current column `j` reads previous column `j-1`; y is unchanged. | interior mean Δx `-0.99960950`; max `|Δx + 1|` `0.01053917`; interior mean Δy `-0.00390620`; max `|Δy|` `0.01171875`. |

The 32-pixel shift is one post-merge Qwen token at a 12×10 grid. Therefore the
negative x displacement verifies that the map is current-to-previous, not
reversed.

## Preliminary real-pair audit (not a policy result)

A live Trace run processed 20 pairs in one sequential RoboTwin episode
(`clean/beat_block_hammer/0`), taking `17.410528` seconds with `11.394699 GiB`
peak allocator memory. The read-only Qwen feature audit reported:

```text
mean raw image-coordinate delta: 83.5964
mean Trace-aligned delta:       79.6953
20 / 20 pairs lower after alignment
mean relative decrease:          4.48%
```

This is evidence that coordinate alignment changes the representation in the
expected direction. It is not yet evidence of a policy improvement, broad task
coverage, OOD robustness, or true occlusion estimation.

## Important limitations / next action

* `valid=1` here means a finite nearest-neighbour trajectory match; it is **not**
  an occlusion mask. Human review must use confidence / nearest-distance proxies
  until an explicit occlusion signal is available.
* The old Day-1 live cache is schema 1 and does not contain transform metadata.
  Do not mix it with the schema-2 cache; regenerate the formal cache with the
  current precompute script.
* Next: manually inspect the 20 four-panel images, then validate correspondence
  across randomly sampled tasks before adding the zero-initialized temporal-delta
  adapter. Do not begin policy training yet.
